# 党员微信群成员核对工具

> 帮老师一键核对：毕业生党员 Excel 名单 vs 微信群实际成员，找出谁还没进群。

## 这是什么？

毕业生党员在离校前需要加入微信群。老师手里有一份 Excel 党员名单，微信群里有实际的成员列表——但一个个比对太累了。

这个工具做的事情很简单：

1. **读取 Excel**（自动识别姓名列）
2. **读取微信群成员截图 OCR 文本**（微信自带 "提取文字" 功能）
3. **自动模糊匹配**，输出：
   - ✅ 谁已经在群里
   - ❌ 谁还没进群（**重点关注**）
   - ⚠️ 谁匹配不确定（需要手动确认）

## 安装

需要 Python 3.7+，然后安装依赖：

```bash
pip install -r requirements_wechat_check.txt
```

或者手动安装：

```bash
pip install pandas openpyxl rapidfuzz rich
```

## 快速开始

### 1. 准备微信群成员文本

1. 微信 PC 端 → 群聊 → 右上角 "…" → 群成员列表
2. 截图（尽量全屏截，让成员尽可能多）
3. 长按截图 → "提取文字"
4. 全选复制 → 粘贴到 `.txt` 文件（保存为 UTF-8 编码）

> **注意**：成员多的话可能需要截多张图，把每次的 OCR 文字都粘贴到同一个 txt 文件里。

### 2. 运行脚本

```bash
# 最简用法（交互式，会提示你输入文件路径）
python party_wechat_check.py

# 指定文件
python party_wechat_check.py --excel "2026届毕业生党员名单.xlsx" --wechat-file "微信群成员.txt"

# 导出结果到 Excel（方便发给老师）
python party_wechat_check.py --excel "名单.xlsx" --wechat-file "members.txt" --output "核对结果.xlsx"

# 显示所有匹配明细
python party_wechat_check.py --excel "名单.xlsx" --wechat-file "members.txt" --verbose
```

## 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--excel` | `-e` | 党员名单 Excel 文件路径 |
| `--wechat-file` | `-w` | 微信群 OCR 文本文件路径 |
| `--name-column` | `-c` | 手动指定姓名列名（默认自动检测） |
| `--threshold` | `-t` | 模糊匹配阈值 0-100（默认 85） |
| `--output` | `-o` | 导出 Excel 结果文件路径 |
| `--verbose` | `-v` | 显示全部匹配明细 |
| `--version` | `-V` | 显示版本号 |

## 匹配原理

脚本用**两轮匹配**来提高准确率：

**第一轮（正向）**：对每个 Excel 姓名，在微信群成员中搜索：
1. 直接包含（"张三" 在 "张三-01班" 中）→ 满分匹配
2. 反向包含（"欧阳泽" 在 "欧阳泽坪" 中）→ 满分匹配
3. 去前缀匹配（去掉 "22级" "硕2024" 等前缀后再试）
4. 模糊匹配（编辑距离算法，处理 OCR 错字）

**第二轮（反向）**：对未匹配的微信昵称，提取其中的中文名片段，反过来搜索 Excel 名单。处理群昵称只写了名字没写全名的情况。

**复姓支持**：自动识别欧阳、司马、上官等常见复姓，避免错误拆分。

## 常见问题

### Q: 为什么有些名字明明在群里却显示 "未找到"？

可能原因：
- 微信 OCR 识别错误（截图不清晰）
- 群昵称改得面目全非（完全看不出原名）
- 名字被其他文本遮挡

建议：手动搜索群成员确认。

### Q: 微信 OCR 提取的结果需要怎么处理？

直接粘贴到 `.txt` 就行，脚本会自动：
- 过滤 "搜索群成员" "添加" 等 UI 文字
- 拆分一行里多个名字（OCR 有时把名字连一起）
- 去除 emoji、装饰符号、长数字

### Q: 名字匹配错了怎么办？

用 `--verbose` 看详细匹配结果，确认是哪个名字被错误匹配了。如果经常出错，可以降低模糊匹配阈值（如 `--threshold 75`）。
